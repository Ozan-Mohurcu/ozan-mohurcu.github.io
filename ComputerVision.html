Gerçek Zamanlı Trafik Tehlike Tahmin Sistemi (MOBESE Entegrasyonu)

İstanbul'daki canlı MOBESE kameralarından gelen video akışını analiz eden, tarayıcı tabanlı gerçek zamanlı bir yapay zeka sistemi geliştirdim. Sistem, nesne tespiti, hız tahmini ve risk skorlama yaparak olası trafik tehlikelerini anlık olarak belirliyor.

Cat & Dog Classification with CNN

In the CNN project, classification and object recognition tasks were performed on image data using deep learning techniques. The model achieved high accuracy by automatically learning visual features with multi-layer convolutional structures. The project includes data preprocessing, model training and performance evaluation stages.

Potato Leaf Disease Classification

Potato leaves were classified as healthy or diseased using image processing techniques. Deep learning models, especially CNNs, were used to automatically detect disease symptoms on leaves. This supports early diagnosis and efficient agricultural practices.
